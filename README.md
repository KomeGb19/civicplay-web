# Civic Play

Superplay-style marketing landing page for Nigeria’s civic education quiz game.

## Stack

- Next.js 15 (App Router) + TypeScript + Tailwind CSS 4
- Lenis smooth scroll + GSAP ScrollTrigger parallax

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

```bash
npm run build
```

Deploy the output to Vercel, then point `civicplay.ng` when ready.
